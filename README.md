# 智慧农业项目资料包

## 文件说明

本仓库包含智慧农业项目的完整资料,由于 GitHub 单文件大小限制(100MB),部分大文件已分卷压缩。

## 文件列表

### 小文件(可直接使用)
- `1-前期资料.zip` - 前期调研和设计资料
- `2-硬件辅助.zip` - 硬件相关文档和辅助材料
- `4-机械部件.zip` - 机械设计图纸和说明
- `5-双端程序.zip` - 前后端完整程序代码

### 分卷文件(需要合并后使用)
- `0-制作日志.zip` (114.45 MB) → 分为 2 卷:
  - `0-制作日志.zip.part1` (95 MB)
  - `0-制作日志.zip.part2` (19.45 MB)
- `3-模型训练.zip` (283.16 MB) → 分为 3 卷:
  - `3-模型训练.zip.part1` (95 MB)
  - `3-模型训练.zip.part2` (95 MB)
  - `3-模型训练.zip.part3` (93.16 MB)

## 合并方法

### Windows 用户
双击运行 `合并文件.bat`,脚本会自动将分卷文件合并为完整的 ZIP 文件。

### Linux/Mac 用户
在终端中执行:
```bash
chmod +x 合并文件.sh
./合并文件.sh
```

### 手动合并
如果脚本无法运行,可以手动执行:

**Windows CMD:**
```cmd
copy /b "0-制作日志.zip.part1"+"0-制作日志.zip.part2" "0-制作日志.zip"
copy /b "3-模型训练.zip.part1"+"3-模型训练.zip.part2"+"3-模型训练.zip.part3" "3-模型训练.zip"
```

**Linux/Mac:**
```bash
cat "0-制作日志.zip.part1" "0-制作日志.zip.part2" > "0-制作日志.zip"
cat "3-模型训练.zip.part1" "3-模型训练.zip.part2" "3-模型训练.zip.part3" > "3-模型训练.zip"
```

合并完成后,可以删除所有的 `.part` 分卷文件。
